# Comedy craft for short AI videos

Sources: UCB "game of the scene" (base reality → unusual thing → heightening → exploring), sketch-writing guides (premise as "what if", escalation with the biggest beat last, surprise endings, cut what doesn't serve the core joke), sitcom writers' rooms (draft fast, punch-up pass, word choice, character-specific jokes), Hitchcock ("tell the story visually; let the talk be part of the atmosphere"), and AI short-drama practice (hook / friction / spike / button; first 3 s must read as a freeze frame; friction visible in frame; cut earlier than feels safe).

## 1. The game of the scene
- **Base reality:** who, where, what's normal. Establish it in one image, fast.
- **Unusual thing:** the one wrong element. It must be specific and visual.
- **Frame it:** a character notices it, or commits to it with total seriousness.
- **Heighten:** "If this is true, what else is true?" Three moves, each bigger. Stop right after the biggest.
- **Explore:** "Why is this true?" The answer often gives the best character joke.
- **Button:** a final line or image that tops the game or flips it.

A sketch is about ONE game. If you can't state it in one sentence, there isn't one.

## 2. Joke mechanics that work in 15–30 s
| Mechanic | How | Example shape |
|---|---|---|
| Misdirection | The setup points one way; the last word turns | "I've reviewed your performance. It was… technically legal." |
| Status reversal | The high-status character loses to the low-status one, or vice versa | The CEO cat ends up asking the intern dog for approval |
| Literalism | A character takes a phrase literally | "Think outside the box." The dog is now sitting outside the box. |
| Escalating commitment | A small lie or rule grows absurdly | Each reply doubles down |
| Specific over general | Precise, odd details are funnier | "a laminated badge," "a 401(k) of tennis balls" |
| Callback | A detail from the first 5 s returns at the button | A prop, a phrase, a running gag |
| Reaction | The cut to the listener's face is the laugh | A silent beat, then the blink |
| Rule of three | Normal, normal, absurd | The third item breaks the pattern |

## 3. Character voice (worked example: a cat-and-dog office comedy)
- **The CEO cat:** precise corporate vocabulary applied to cat life; wounded pride; never raises his voice; loses with dignity. Says "per my last email" to a dog.
- **The intern dog:** literal, joyful, unstoppable optimism; misunderstands in a way that is accidentally right; short, excited lines.
- **The human owner:** dry, the only adult in the room; one line, usually the knife; sees through the cat.

Write the same three lines for your own cast before drafting: vocabulary, attitude, and how each one loses.

## 4. Structure for 15–30 s
| Beat | Time | Job |
|---|---|---|
| Hook | 0–2 s | A striking image + a line that opens a question |
| Game | 2–8 s | The unusual thing, framed |
| Heighten ×2–3 | 8–20 s | Each move bigger; visible action, not just talk |
| Spike | ~20 s | The biggest escalation |
| Button | last 2–4 s | Top or flip; cut fast after it |

## 5. Script rubric (score 1–10; ship at avg ≥ 8, none < 7)
| Criterion | 10 looks like |
|---|---|
| Premise | Specific, surprising, instantly clear, would make someone stop scrolling |
| Game | One clear game, heightened 2–3 times, biggest last |
| Lines | Every line has a turn or a laugh; no exposition; quotable |
| Character | Lines only that character could say |
| Visual | Works muted; every beat has visible action; hook reads as a still |
| Button | Tops or flips the game; you'd rewatch for it |
| Producibility | ≤ 3 characters, 1 location, actions the video model can perform (no complex hand work, no crowds) |

## 6. Anti-patterns (a rejected early episode had all of these)
- A premise that is just a situation ("a performance review") with no unusual thing.
- One joke ("you're the only employee") repeated instead of heightened.
- Filler lines from a third character that add nothing ("Does he get a raise?").
- A predictable button that the audience saw coming.
- Lines that sound written, not spoken.
